# 垂心四面体扫描：五点以上共球

1166 个点的全量共球扫描与分类，2026-10-20。点集见《垂心四面体特殊点库》，共线、共面、共圆见《垂心四面体扫描：共线、共面、共圆》。

## 摘要

- <b>点</b>：912 个原子中心 + 254 个轨道点 = 1166 个。
- <b>找到</b>：候选球 2,471,711，6 个样本上都成立的 <b>1,489,506</b> 个，与一般四面体那轮（1,622,536）同量级。
- <b>筛选后</b>：未解释 <b>1,453 个</b>，按顶点对称合并为 <b>196 类</b>。
- <b>结论</b>：96.4% 的球来自「三对点关于同一已知球互为反演」。剩下的 196 类骨架高度分散（185 种），没有可以一网打尽的机制，需要逐类看。

## 二、本轮加的规则

前四条沿用上一轮一般四面体扫描时加的，第五条是本轮新写的，第六条无效（见第五节）。

| 规则 | 吃掉 | 说明 |
|---|---|---|
| 圆加一点 | 37,162 | 球上有 n−1 点共面，即一个圆加一点，必然共球 |
| 由已知圆拼成 | 12,589 | 两对点关于同一已知球互为反演即确定一个正交圆（不必凑满三对）；若干这样的圆相邻共用两点即可串成一个球 |
| 与已知球正交，反演对不贡献独立条件 | 2,331 | 见下 |
| 相对误差（扫描器） | — | 本轮由任务方在 `ospheres.py` 中完成，分类器里的四处（`same_sphere` 一处、`thales` 两处、`orthogonal_to` 一处）由本轮改为相对判据加极小绝对项兜底 |
| 构造半径 | — | 原版已用带符号的幂 `pw`，极球为虚球（`pw < 0`）时同样适用，无需改动 |
| 导出球 | 1 | 无效，见第五节 |

<b>「与已知球正交，反演对不贡献独立条件」</b>是上一轮在一般四面体上证明过的机制的一般形式：

> 过一对关于球 ω 互为反演的点的球必与 ω 正交；反过来，与 ω 正交的球在 ω 的反演下不变，所以球上每出现一对反演点就少一个独立条件。球有 4 个自由度，于是 <b>点数 − 反演对数 ≤ 4</b> 时这个球是被迫的，不是巧合。

这一条合计吃掉 2,331 个（内切球 1,600、外接球 617、极球 96、棱中点球 18）。

<b>判定顺序会重新分配计数。</b>本轮先把这条规则排在第二位试跑，它吃掉 37.6%；挪到最后之后只剩 0.16%，而「三对以上反演」从 59.2% 升到 95.9%。同一批球、同样的规则，顺序一换计数差两个数量级，所以<b>各类计数只在固定顺序下可比</b>。最终采用的顺序把这条放在最后，使计数口径与一般四面体那轮一致。

## 三、三项检查

<b>1. 基准对得上。</b>300 个点试跑，只用样本 0 时候选 31,226、复核后 31,212，与任务书给出的参考数字完全一致。

<b>2. 复核通过率。</b>

| | 样本 0 | 样本 1 |
|---|---|---|
| 300 点 | 31,212 / 31,226 = 100.0% | 31,514 / 31,528 = 100.0% |
| 全量 | 1,479,554 / 1,522,573 = 97.2% | 1,455,610 / 1,464,417 = 99.4% |

对照：上一版（点集含远点、容差按整体尺度）通过率只有 9.7%。

<b>3. 完整性检查。</b>`sph_check.py` 随机取三对关于外接球（内切球）互为反演的点，六点必共球，检查扫描有没有找到：

| | 反演对 | 检查组数 | 没找到 |
|---|---|---|---|
| 外接球 | 165 | 400 | <b>0</b> |
| 内切球 | 162 | 397 | <b>0</b> |

<b>双样本加固。</b>第 1 步原本只在样本 0 上找候选，是单点失败结构。本轮改为在样本 0 和样本 1 上各找一次取并集，并加了两道闸门（通过率低于 80% 停、完整性检查有漏停）。300 点上，并集比样本 0 单独多找到 <b>570 个球</b>（+1.8%），其中包含一个 7 点球；用最小二乘独立复核，这 570 个的残差中位数 2.1e−16，与样本 0 找到的那批（2.9e−16）没有区别，随机五点组的对照是 1.4e−02。即使是重排后「最一般」的样本，单独扫仍会漏。

## 四、已看出的结构

<b>1. 顶点 + 内切球切点 + 顶点关于对面的对称点。</b>含这三点的球共 161 个，<b>全部与内切球正交，且「点数 − 内切球反演对数」恰好等于 4</b>，因此全部被第三条规则吃掉，不在未解释列表中。

成因在上一轮已证明：面 0 所在平面切内切球于切点，顶点 V₀ 与其镜像关于该面对称，故球心必落在该面内，于是 |CI|² = |C−切点|² + r² = R² + r²，自动与内切球正交；正交球在内切球反演下不变，任一点 P 在球上就把 inv(P) 一并带上。上一轮一般四面体的 244 类未解释里，这个机制覆盖 180 类；本轮因为已写成规则，它们不再出现在残余中。

<b>2. 残余以垂心四面体特有的 H 系列点为主。</b>196 类中有 107 类含 H 系列点（97 类含 HL 轨道族、23 类含 H 编号中心），反复出现的是：

- HL7 = H 关于面 i 的对称点
- HL8 = H 关于棱 ij 中点的对称点
- HL9 = H 关于棱 ij 所在直线的对称点
- HL12 = 棱中点关于极球的反演点

这些点在一般四面体里不存在，所以这部分是本轮真正的新内容。

<b>3. 骨架高度分散。</b>196 类共有 185 种不同骨架，覆盖最多的一种只有 5 类（HL12、HL8、HL9、L43）。与一般四面体那轮形成对比——那轮 244 类里有 168 类共用同一个骨架。本轮没有可以一网打尽的机制。

<b>4. 点数多的球值得优先看。</b>出现了 7、9、10、12 点的球（一般四面体那轮最多 8 点）。点数越多越不像巧合，其中那个 12 点球是 HL12、HL7、HL8、HL9、L1、L33、L43 的组合。

## 五、已确认没用的思路

<b>导出球筛子。</b>已知球在以 O、I、G、H 为中心、比例 −3 到 3 的位似下的像，共 140 个，逐个比对。<b>只命中 1 个，未解释仅减少 1 类。</b>

动机是：HL8 六个点确实全部落在「棱中点球以 H 为心放大 2 倍」的球上（误差 1e−16，已验证）。但这只说明<b>这些点</b>是位似导出的，不说明<b>用到这些点的球</b>是某个已知球的位似像——那个导出球本身在扫描里只出现一次。把「点怎么来的」当成「球怎么来的」，方向错了。

教训：验证了机制不等于验证了筛子。应当先统计有多少未解释的球能被候选规则覆盖，再决定写不写；这一步只要几行，可以在动手之前就否掉它。

## 六、下一步
