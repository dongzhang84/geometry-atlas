# 九点圆定理系统：前三轮数值试探的代码

依赖：Python 3、numpy、mpmath（只有两个复核脚本用到）。在每个子目录里直接运行即可，例如：

```
cd round1 && python3 probe.py
```

每个脚本都在几秒到一两分钟内跑完，结果打印到屏幕。

## round1：三角形的 35 个名点

| 文件 | 作用 |
|---|---|
| probe.py | 主程序。随机取 25 个三角形，按公式算出 35 个点，检查所有三点共线、四点共圆，只保留在全部三角形上成立的，再合并成最大组。对应主文档表 1–3 |
| check.py | 用 mpmath 50 位精度复核关键关系（Feuerbach、Mandart 圆过 F 等） |

## round2：三角形加任意点 P

| 文件 | 作用 |
|---|---|
| probe2b.py | 主程序。30 个随机构型，34 个点（Y4 与 Poncelet 点合并后）、5 条曲线；检查共线、共圆、点在曲线上。已加入重合点去重，修正了早期版本把三条曲线误并成「14 点圆」的问题。对应主文档表 4–8 |
| check2.py | 用 mpmath 40 位精度复核 Poncelet 点的性质（在九点圆、塞瓦圆、垂足圆上） |

## round3：新第三轮「把圆推广成同形的椭圆和双曲线」

对应《第三轮.md》。

| 文件 | 作用 |
|---|---|
| geo.py | `metric(A,B,C,P)` 求让 P 成为垂心的尺子 S（三边长度平方不同号时返回 None）；`points(A,B,C,S)` 在尺子 S 下作出第一轮的 35 个点 |
| scan.py | 主程序。用法：`python3 scan.py ell 1`（椭圆情形）或 `python3 scan.py hyp 2`（双曲线情形），最后一个参数是随机种子。检查三点共线和四点共同形曲线，输出 37 组共线、25 条共曲线，结果另存为 res_ell.json / res_hyp.json |
| feu_core.py | `setup(A,B,C,P)`：求九点二次曲线 Γ，以及与三边都相切的 4 条同形曲线；`tangent_check`：两条同形曲线是否相切 |
| feucheck.py | 椭圆、双曲线情形各 30 个构型，检查 Γ 与「内切圆」「旁切圆」都相切（Feuerbach 推广，对应《第三轮.md》表 4） |
| region.py | 在固定三角形上按网格扫描 P，统计椭圆、双曲线、「内切圆」虚实的分区（对应《第三轮.md》第三节） |

《第三轮.md》第三节的区域规则是用 sympy 符号推导的，推导代码很短，没有单独存文件。思路是：解出让 P 成为垂心的 S，再化简三边长度平方与 det S，得到 det S ∝ uvw，三边长度平方 ∝ u(1 − u)、v(1 − v)、w(1 − w)。

## 判据和阈值

- 共线：叉积归一化后，第一、二轮 < 10⁻⁷，第三轮 < 10⁻⁸。
- 共圆：第一轮 < 10⁻⁹，第二轮 < 10⁻⁸。第三轮的共同形曲线：每点一行 (XᵀSX, x, y, 1)，4×4 行列式按列归一化后 < 10⁻⁸。
- 第一、二轮还要求参与比较的点两两不重合（距离 > 10⁻⁶ 或 10⁻⁵）。
- 只保留在全部随机构型上都成立的关系；关键结果另用 mpmath 高精度复核。
