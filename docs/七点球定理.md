# 七点球定理

一般四面体上的一条共球定理：每个顶点给出七个共球的点。它是《[一般四面体定理扫描](一般四面体定理扫描.md)》共球一层筛到最后唯一剩下的关系（见该文 5.3 节），随后被证明。本文从那篇扫描报告中独立出来，整理于 2026 年 10 月 20 日。

可交互的三维图见专题页 `explore/nine-point.html#sevenpoint`。

<b>记号</b>：四面体 V0V1V2V3，外接球球心 O、半径 R，重心 G。对顶点 V0，记它的对面 V1V2V3 为面 0，面 0 的外心为 O′、垂心为 H′。

## 定理

对任意四面体和它的任一个顶点 V0，下面七点共球：

| | 点 | 作法 |
|---|---|---|
| 1 | A | 直线 V0G 与外接球的第二个交点 |
| 2 | B | 外接球在 V1、V2、V3 处的三个切平面的交点（切线四面体的顶点，也是面 0 所在平面关于外接球的极点） |
| 3 | C | 4G − 3V0（V0 关于面 0 的重心、按 −2 倍位似的像，即反补四面体的顶点） |
| 4 | H′ | 面 0 的垂心 |
| 5 | E | G 关于外接球的反演点 |
| 6 | D | 4G − 3O：以 O 为中心、把 G 放大 4 倍得到的点（反补四面体的外心） |
| 7 | F | 4O′ − 3O：以 O 为中心、把面 0 的外心 O′ 放大 4 倍得到的点 |

四个顶点各给出一个这样的球。

图：以 V0 为例的七点球（紫色）。灰色网格是外接球（球心 O），浅蓝面是 V0 的对面 V1V2V3（外心 O′）。红点 1–7 依次是表中的 A、B、C、H′、E、D（= 4G−3O）、F（= 4O′−3O）。三条虚线正对应证明里用到的三条共线关系：橙色是 V0、G、A、C 共线（G 把中线分成 3:1，这给出条件 (iii)）；绿色是欧拉线上的 O、G、E、4G−3O（E 与 4G−3O 是反演 J 的一对，给出条件 (i)）；蓝色是 O、O′、B、4O′−3O 共线且垂直于面 V1V2V3（B 与 4O′−3O 是 J 的另一对，给出条件 (ii)）。三条线各交出一个线性方程，球心就定下来了，H′ 和 A 随之自动落在球上。

## 证明

（Claude Code，2026-10-19）把外接球归一化：取 O 为原点、R = 1。记 s = V1 + V2 + V3，于是 G = (V0 + s)/4；O′ 是 O 在面 0 上的投影，H′ = s − 2O′。

关键一步是先固定球的形状族。设 J 是以 O 为心、半径 2R 的反演，J(X) = 4X/|X|²。注意 E = inv(G)、B = inv(O′)，其中 inv 是关于外接球的反演（极点就是垂足的反演像，|OB|·|OO′| = R²）；直接验证 J(E) = 4G、J(B) = 4O′。过一对 J 对应点的球必与 S(O, 2R) 正交，所以要找的球 Σ 与 S(O, 2R) 正交，等价于 O 对 Σ 的幂等于 4，即

> Σ：|X|² − 2c·X + 4 = 0，　c 为球心。

这样未知数只剩 c，而「X 在 Σ 上」是关于 c 的一个<b>线性</b>方程：2c·X = |X|² + 4。七个点给出：

- <b>E = inv(G)</b> 在 Σ 上 ⟺ 2c·G = 4|G|² + 1　(i)　（代入 E = G/|G|²，两边乘 |G|² 即得；等价地 4G 在 Σ 上）
- <b>B = inv(O′)</b> 在 Σ 上 ⟺ 2c·O′ = 4|O′|² + 1　(ii)　（同理；等价地 4O′ 在 Σ 上）
- C = 4G − 3V0 在 Σ 上，用 (i) 消去后 ⟺ 2c·V0 = 8G·V0 − 3　(iii)
- 4G、4O′ 分别是 E、B 在 J 下的像，而 Σ 与 S(O, 2R) 正交即 J-不变，所以它们自动在 Σ 上。

取 c 为 (i)(ii)(iii) 这三个线性方程的解（三个方程三个未知数，一般位置下唯一）。剩下两点自动成立：

<b>H′。</b>代入 (i)(ii)(iii)，所需等式化简为 s·O′ = 3|O′|²。而 V1、V2、V3 都落在过 O′ 且垂直于 OO′ 的平面上，故 (Vi − O′)·O′ = 0，即 Vi·O′ = |O′|²，三式相加即得。

<b>A。</b>写 A = V0 + t(G − V0)，由 |A| = 1 且 |V0| = 1 得 t = 2(1 − G·V0)/|G − V0|²。于是

> 2c·A = 2c·V0 + t(2c·G − 2c·V0) = (8G·V0 − 3) + t · 4|G − V0|² = (8G·V0 − 3) + 8(1 − G·V0) = 5，

而 |A|² + 4 = 1 + 4 = 5，两边相等。∎

换句话说，Σ 就是<b>过 E、B、C 三点且与 S(O, 2R) 正交的那个球</b>（球有 4 个自由度，三点加正交恰好 4 个条件），而 4G、4O′ 是 E、B 的 J-像，A 和 H′ 则由上面两段计算自动落上。原先缺的那一步（球为什么还过 4O′ − 3O）在这个写法下不再是额外条件：它就是定出球心的三个方程之一。

Σ 必为实球：球上有 A 这样的实点，故半径² = |A − c|² ≥ 0。

## 验证

按 (i)(ii)(iii) 解出 c 再代回，300 个随机四面体上七点全部满足方程；另取 15 个顶点坐标全为有理数的四面体（用勾股四元组放在单位球上），105 次代入<b>精确为 0</b>。

扫描阶段另有两项独立验证：

- 数值：在 9 个随机四面体上成立，误差 10⁻¹⁶ 量级；作为对照，换成随机点，误差在 10⁻² 量级。
- 精确：取 7 个坐标全为有理数的四面体（外心放在原点，R = 1，用勾股数和球极投影参数化），七点中任取五点的 21 个行列式全部严格等于 0。

## 退化情形

球心 c 由三个线性方程定出，系数矩阵是 2[G; O′; V0]（以 O 为原点）。所以构形退化当且仅当

> <b>det[G, O′, V0] = 0</b>，即 O、G、O′、V0 四点共面。

两种特殊情形都包含在内：G = O（外心与重心重合，此时 E 在无穷远、4G − 3O 退回 O）；O′ = O（某个面所在平面过外心，即该面的外接圆是大圆，此时极点 B 在无穷远）。

退化不是定理失效，而是球变成平面。沿一族四面体把 det 推向 0，球半径按 1/det 发散，而七点的共面程度同比例趋于 0：

| det | 球半径 / R | 七点共面程度 σ₃/σ₁ |
|---|---|---|
| 8.9 × 10⁻⁴ | 118 | 5.6 × 10⁻³ |
| 8.9 × 10⁻⁵ | 1195 | 5.6 × 10⁻⁴ |
| 8.9 × 10⁻⁶ | 11965 | 5.6 × 10⁻⁵ |

所以在把球与平面同等看待的意义下（Möbius 几何），定理对所有四面体成立：七点共球或共面。

## 球上恰好是这七个点；四个球的关系

<b>没有第八个点。</b>把 1096 个库点逐一代入 V0 的七点球，6 个四面体上都落在球上的恰好是 5 个库点——T171 = inv(G)（即 E）、L4.0 面垂心（H′）、L33.0 重心的外接球塞瓦点（A）、L37.0 切线四面体顶点（B）、L38.0 反补四面体顶点（C）——加上库外的 4G − 3O 和 4O′ − 3O，正好七个。另外试过十几个库外的自然候选（Monge 点、面重心、十二点球心、面的九点圆心、2O′、3G − 2V0、V0 关于面 0 的镜像等），没有一个在球上。

<b>四个球有一个共同的正交球。</b>证明的第一步对四个顶点一视同仁，所以四个七点球<b>都与以 O 为心、半径 2R 的球正交</b>。于是 O 对四个球的幂都等于 4R²：

> <b>推论</b>：四个七点球两两的根面都经过外心 O，O 是它们的根心。

300 个随机四面体上，O 对四球的幂彼此之差恒为 0。四个球心一般既不共线也不共面（σ₂/σ₁、σ₃/σ₁ 的中位数分别是 0.38、0.13），所以四球不共轴，除了共同的正交球之外没有更强的关系。

## 和三角形的关系

定理里的 B（面所在平面关于外接球的极点）和 H′（面的垂心）在三角形里都没有直接对应，所以这是一个三维特有的结构，不是三角形定理的简单推广。

## 附：论文草稿（中文，2026-10-19）

草稿,2026-10-19。中文稿;若投稿需另译英文。

### 摘要

设 V₀V₁V₂V₃ 为一般四面体,外接球球心 O、半径 R,重心 G。对每个顶点 V₀,记对面 V₁V₂V₃ 为面 0,其外心 O′、垂心 H′。本文证明下列七点共球:直线 V₀G 与外接球的第二个交点 A;面 0 所在平面关于外接球的极点 B(即外接球在 V₁、V₂、V₃ 处三个切平面的交点,也是切线四面体的顶点);C = 4G − 3V₀(反补四面体的顶点);H′;G 关于外接球的反演点 E;以及 4G − 3O 与 4O′ − 3O。四个顶点各给出一个这样的球,且四球都与以 O 为心、半径 2R 的球正交,因而 O 是它们的根心。证明只用到反演与一次线性计算;在把球与平面统一看待的意义下(Möbius 几何),结论对一切四面体无例外。

### 一、引言

三角形的九点圆及其邻近结果(欧拉线、Feuerbach 定理)在十九世纪已被充分开发。四面体方向上,已知的对应物主要是 Monge 点、欧拉线(O、G、Monge 点共线)和十二点球(过四个面重心与四个 Monge 三等分点)。但一般四面体比三角形"松"得多——四条高一般不共点,Gergonne、Nagel 型的塞瓦线也不共点——因此许多三角形中的巧合在四面体中并不成立,可以期待的新结构相应地少。

本文给出一条似乎未被记载的结果。它的七个点里,有两个(极点 B 与面的垂心 H′)在三角形中没有直接对应物,所以它不是某条三角形定理的简单升维。

本文结果不是人工猜出来的,而是一次穷举扫描的残余:在一个为一般四面体建立的点库(1957 个"中心"与 52 组、228 个"轨道点")中取 1096 个点,扫描全部共线、共面、共圆、共球关系,再用若干机械的筛子剔除由作法、反演、代数恒等式直接推出的部分。共球一层找到 1,622,536 个,其中 99.9% 以上来自反演;逐层筛选后只剩一类,即本文的定理。这一发现路径本身也许值得一提,见第六节。

### 二、记号与预备

取 O 为原点并令 R = 1(相似变换下不失一般性),于是 |Vᵢ| = 1。记

- s = V₁ + V₂ + V₃,　G = (V₀ + s)/4;
- O′ = O 在面 0 上的正交投影,即面 0 的外心。由 (Vᵢ − O′) ⊥ O′ 得

  <b>(2.1)　Vᵢ · O′ = |O′|²　(i = 1, 2, 3),　故 s · O′ = 3|O′|²;</b>

- H′ = s − 2O′(三角形中垂心等于三顶点之和减去二倍外心);
- inv 表示关于外接球的反演,inv(X) = X/|X|²。则 E = inv(G);而面 0 所在平面的极点满足 |OB|·|OO′| = R²,方向与 O′ 相同,故 B = inv(O′);
- C = 4G − 3V₀;
- A 是直线 V₀G 与外接球的第二个交点;
- J 表示以 O 为心、半径 2R 的反演,J(X) = 4X/|X|²。直接计算得 <b>J(E) = 4G,J(B) = 4O′</b>。

<b>Möbius 球。</b> 把球与平面统一写成

<b>(2.2)　α|X|² − 2c·X + 4α = 0,　(α, c) ∈ ℝ × ℝ³ 不全为零,差一个倍数视为同一个。</b>

α ≠ 0 时这是一个球,其球心 c/α、且 O 对它的幂等于 4,即与以 O 为心、半径 2 的球正交;α = 0 时退化为一个平面。点 X 落在 (2.2) 上的条件是

<b>(2.3)　α(|X|² + 4) = 2c·X,</b>

这是关于未知数 (α, c) 的<b>线性</b>方程。于是"若干点共球"变成一个齐次线性方程组的秩的问题。

### 三、主要定理

> <b>定理 1.</b> 对任意四面体 V₀V₁V₂V₃ 与它的任一顶点 V₀,存在唯一的 Möbius 球过下列七点:
>
> A,　B,　C = 4G − 3V₀,　H′,　E = inv(G),　4G − 3O,　4O′ − 3O。
>
> 当 O、G、O′、V₀ 不共面时它是一个真实的球;四点共面时退化为一个平面。

<b>证明.</b> 把七点逐一代入 (2.3)。

(1) <b>E 与 4G 给出同一个方程。</b> 由 E = G/|G|²,(2.3) 为 α(1/|G|² + 4) = 2c·G/|G|²,乘 |G|² 得

<b>(3.1)　2c·G = α(4|G|² + 1).</b>

由 4G,(2.3) 为 α(16|G|² + 4) = 8c·G,除以 4 后同样是 (3.1)。这正是 J-不变性在方程层面的表现。

(2) <b>B 与 4O′ 同理给出</b>

<b>(3.2)　2c·O′ = α(4|O′|² + 1).</b>

(3) <b>C。</b> |C|² + 4 = 16|G|² − 24G·V₀ + 13,而 2c·C = 4(2c·G) − 3(2c·V₀)。代入 (3.1) 整理得

<b>(3.3)　2c·V₀ = α(8G·V₀ − 3).</b>

(4) <b>H′ 自动成立。</b> 由 H′ = 4G − V₀ − 2O′ 与 (3.1)–(3.3),

2c·H′ = 4·α(4|G|²+1) − α(8G·V₀−3) − 2·α(4|O′|²+1) = α(16|G|² − 8G·V₀ − 8|O′|² + 5)。

另一方面 |H′|² + 4 = 16|G|² + 4|O′|² + 1 − 8G·V₀ − 16G·O′ + 4V₀·O′ + 4。两式相等等价于

−12|O′|² + 16G·O′ − 4V₀·O′ = 0,　即　s·O′ = 3|O′|²,

其中用到 4G = V₀ + s。而这正是 (2.1)。

(5) <b>A 自动成立。</b> 写 A = V₀ + t(G − V₀)。由 |A| = |V₀| = 1 得 t = 2(1 − G·V₀)/|G − V₀|²。注意 (3.1) 与 (3.3) 之差给出 2c·G − 2c·V₀ = α(4|G|² − 8G·V₀ + 4) = 4α|G − V₀|²,于是

2c·A = 2c·V₀ + t(2c·G − 2c·V₀) = α(8G·V₀ − 3) + t·4α|G − V₀|² = α(8G·V₀ − 3) + 8α(1 − G·V₀) = 5α,

而 α(|A|² + 4) = 5α。两边相等。

因此七点给出的七个线性方程只有 (3.1)、(3.2)、(3.3) 三个独立的,四个未知数 (α, c) 上的系数矩阵秩至多为 3,必有非零解。又 (3.1)–(3.3) 对固定 α 把 2c 唯一定出(当 det[G, O′, V₀] ≠ 0),故解在相差倍数的意义下唯一:det ≠ 0 时取 α = 1 得一个球;det = 0 时只能 α = 0,得一个平面。∎

<b>注.</b> 所得的球必为实球:A 是球上的实点,故半径² = |A − c/α|² ≥ 0。

> <b>推论 2.</b> 四个顶点给出的四个七点球,都与以 O 为心、半径 2R 的球正交。因此 O 对这四个球的幂都等于 4R²,<b>O 是四球的根心</b>,两两的根面都过 O。

<b>证明.</b> 定理 1 的证明中,方程族 (2.2) 的选取对四个顶点完全相同,而 α = 1 时 (2.2) 即"O 对该球的幂等于 4R²",这正是与 S(O, 2R) 正交的条件。∎

> <b>命题 3(退化).</b> 构形退化当且仅当 O、G、O′、V₀ 四点共面,即 det[G, O′, V₀] = 0。其中包含两种特殊情形:G = O(外心与重心重合);O′ = O(面 0 所在平面过外心,即该面的外接圆是大圆)。退化时七点共面。

### 四、恰好是这七个点

在建立本文结果的点库(1096 个点)中逐一检验,落在 V₀ 的七点球上的恰好是上述七点中属于库内的五个(A、B、C、H′、E),无第八个。库外另检验了十余个自然的候选点——Monge 点、面重心、十二点球心、面的九点圆心、2O′、3G − 2V₀、V₀ 关于面 0 的镜像等——均不在球上。

四个球心一般既不共线也不共面(在 262 个随机四面体上,奇异值比的中位数分别为 0.38 与 0.13),故四球不共轴;除推论 2 的公共正交球外,没有更强的关系。

### 五、验证

- <b>数值。</b> 按 (3.1)–(3.3) 解出 c 后代回,300 个随机四面体上七点全部满足球方程;作为对照,换成随机七点,残差在 10⁻² 量级。
- <b>精确。</b> 取 15 个顶点坐标全为有理数的四面体(用勾股四元组把顶点放在单位球上),105 次代入在有理数算术下<b>严格等于零</b>。
- <b>退化。</b> 沿一族四面体把 det[G, O′, V₀] 推向 0,球半径按 1/det 发散,而七点的共面程度同比例趋于 0,与命题 3 一致。

### 六、结果的来源

本文结果来自一次系统扫描,过程如下。先仿照三角形中心百科(ETC)的做法,为一般四面体建立点库:由十个基本作图出发,经权重族、衍生四面体、一元与二元操作生成 1957 个"中心"(定义不依赖顶点编号),另收 52 组、228 个"轨道点"(每个顶点、面、棱或每对对棱一个)。取其中 1096 个点,在多个随机四面体上扫描全部三点共线、四点共面、四点共圆与五点共球关系,并在 6 个四面体上复核。

共球一层得 1,622,536 个,其中由"三对点关于同一已知球互为反演""由已知圆拼成""圆加一点"等机械判据可解释的占 99.9% 以上;自动筛选后余 244 类,再经人工分拣(与内切球正交 180 类、按作法的反演对称 55 类、对任意点成立 4 类、等角共轭点的垂足球 2 类等)后,只剩一类,即定理 1。

把穷举扫描当作发现手段,其价值不只在于找出这一条:同一轮扫描中,共线、共面、共圆三层分别只剩 1、8、0 条未能解释的关系,这为"一般四面体在这几层上几乎没有作法以外的东西"提供了量化的证据。

### 七、文献说明

笔者未能在以下范围内找到本文定理:英文术语的各种组合检索;中文检索;arXiv 与 Forum Geometricorum 方向关于四面体中心、Monge 点、欧拉线、十二点球的文章。

<b>Altshiller-Court《Modern Pure Solid Geometry》(1935/1964)已全文检索。</b>该书第九章"Recent Geometry of the Tetrahedron"第 4 节正是"Spheres Related to the Tetrahedron",其中 (a)"Analogues of the Nine-Point Circle"给出两个球:<b>十六点球</b>(§763,过外心 O 与它的等角共轭点 O′ 在四个面上的八个投影及其关于球心的对称点,即 (O) 与 (O′) 的根球)与<b>十二点球</b>(§764–767)。两者都与本文的球不同:本文的球每个顶点一个、共四个,而这两个球对整个四面体各只有一个。

书中与本文最接近的三处,核对后均非同一结果:

- 第九章 §763 的十六点球与 §764 的十二点球,如上;
- 第七章习题 26:"若四面体的外接球与重心固定,则以各中线为直径的球正交于一个定球"。构造不同;数值核验表明 O 对这些球的幂不是常数(在 100 个四面体上介于 −0.82 与 0.99 之间),而本文四球的幂恒为 4R²,故不是同一族;
- 第七章习题 5(a):以四顶点为心、各中线为半径的四球,其根心在欧拉线上。构造亦不同。

另检索了 tangential tetrahedron(12 处)、anticomplementary(5 处)、Monge point(28 处)、twelve-point(28 处)、isogonal(71 处)、polar sphere(15 处)等词条的全部出现位置,以及含"cospherical""lie on a sphere"的全部命题,未见本文的七点组合。

<b>AoPS 社区站内检索</b>(2026-10-19):以 tetrahedron seven point sphere、tangential tetrahedron sphere orthocenter、anticomplementary tetrahedron 等组合检索,未见相关讨论。命中的多为初等竞赛题,与四面体中心几何无关;唯二涉及本主题的是两条关于十二点球的帖子,均为已知结果。需说明该站检索为宽松的关键词匹配而非精确短语匹配(检索 anticomplementary tetrahedron 时返回的是一般的 tetrahedron 帖子),因此这一轮的排除力有限。

须说明,文献中"七点球"一词另有所指:它通常指垂心四面体中过棱中点等点的球(亦称 24 点球),与本文对象无关。十二点球是已知结果,本轮扫描中亦被重新找到。"垂心四面体的极球与十二点球正交"在结构上与推论 2 相近,但只对垂心四面体成立。

因此本文只能陈述"未检索到",不能断言其为新结果。
