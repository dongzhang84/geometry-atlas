# 四面体：代码

依赖：Python 3、numpy、scipy。每个子目录自带一份 tpts.py（随机四面体与第一轮的点），在子目录里直接运行即可。

## library：四面体特殊点库（对应《四面体特殊点库》）

| 文件 | 作用 |
|---|---|
| tetlib.py | 核心：四面体对象 T（面积、体积、外心、内心等）；16 种「每个顶点／对面一个」的量；16 个衍生四面体；10 个基本作图中心 |
| build.py | 生成中心库：基本作图 → 权重族 → 衍生四面体 → 一元操作 → 二元操作；检查「是中心」（换顶点次序结果不变）、有定义、去重，输出 tetlib.pkl（1957 个中心在 6 个随机四面体上的坐标、名称、别名） |
| orbits.py | 52 组轨道点（每个顶点／面、每条棱、每对对棱一个）的定义 |
| orbcheck.py | 检查轨道点：有定义、换顶点编号整组不变、组内不重合、组间去重，输出 orbits.pkl |
| isocheck.py | 验证四面体等角共轭公式 S_i²/x_i（距离乘积性质） |
| tetlib.pkl、orbits.pkl | 生成好的坐标数据，可直接用于扫描 |

运行：`python3 build.py`（约 30 秒），然后 `python3 orbcheck.py`。

## round1：第一轮 60 个点的扫描（对应《四面体特殊点》）

| 文件 | 作用 |
|---|---|
| tpts.py | 60 个点（含面上、棱上的点）的作法；随机一般四面体与垂心四面体 |
| scan.py | `python3 scan.py general` 或 `ortho`：共线、共面、共球扫描，输出 res_general.json / res_ortho.json |
| spheres.py | 共球的单独扫描与筛选，输出 sph_*.json；*_good.json 是保留下来的结果 |
| check_ortho.py | 垂心四面体构造的自检 |

## explore：换尺子的试探（尚未写进文档）

| 文件 | 作用 |
|---|---|
| quadric.py | 四面体加一点 P 时，10 个中点是否共二次曲面（结论：不共） |

| locus.py | Q 变化时 Q-垂心的轨迹：三次曲面，过 4 个顶点和 6 条棱 |
| cayley.py | 轨迹方程拟合为 Σ c_l/x_l = 0，系数 c 尚未认出 |
