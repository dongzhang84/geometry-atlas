# 代码

`docs/` 下几篇长文背后的数值试探代码，按研究对象分成两个项目。依赖都是 Python 3 + numpy（个别脚本另需 scipy、sympy、mpmath、matplotlib）。

| 目录 | 对应文档 | 内容 |
|---|---|---|
| `九点圆/` | 《九点圆定理系统》《…第四轮：扩大搜索范围》 | 四轮数值试探：三角形名点的共线共圆、加一点 P 的仿射推广、换尺子的同形椭圆与双曲线、扩大到 ETC 的 753 个中心 |
| `四面体/` | 《四面体特殊点库》 | 四面体的点库与扫描：1957 个中心、52 组轨道点、第一轮共线共面共球扫描，以及尚未写进文档的「换尺子」试探 |

每个目录下还有一份自己的 README，逐个说明脚本的作用、判据和阈值。
